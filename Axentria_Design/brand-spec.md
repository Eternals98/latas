# Axentria — Brand Specification

## Core DNA
"Modern ledger" — the heritage of the paper sales book (libro de ventas) brought to a high-performance web interface. Warm, confident, and trustworthy.

## Color Palette (OKLch)
Derived from existing Hex/CSS variables:

| Token | OKLch Value | Usage |
| :--- | :--- | :--- |
| `--bg` | `oklch(98% 0.015 80)` | Base app background (Paper 100) |
| `--surface` | `oklch(100% 0 0)` | Cards, panels, modals |
| `--fg` | `oklch(20% 0.02 240)` | Primary text, headings (Ink 900) |
| `--muted` | `oklch(60% 0.02 80)` | Secondary text, labels (Slate 500) |
| `--border` | `oklch(90% 0.01 80)` | Standard dividers and hairline borders |
| `--accent` | `oklch(75% 0.15 85)` | Primary action, highlights (Brass 400) |
| `--positive`| `oklch(65% 0.15 150)`| Success, income (Sage 500) |
| `--danger` | `oklch(60% 0.20 30)` | Error, outflow (Coral 500) |

## Typography
- **Display:** `Instrument Serif`. 400 weight. Used for large headers and "editorial" moments.
- **Body:** `Manrope`. 400-700 weight. Primary UI font.
- **Mono:** `JetBrains Mono`. 400-600 weight. Used for currency, numbers, and technical metadata.

## Layout Posture
- **Radii:** Balanced (10px for cards, 6px for buttons).
- **Borders:** Hairline (1px) with subtle contrast.
- **Shadows:** Minimal and soft. Feels like ink on paper, not depth.
- **Density:** POS-optimized (standard "comfy" spacing for touch/mouse accuracy).

## Key Components
- **Sidebar:** Dark Ink or warm Paper depending on mode.
- **Buttons:** Bold primary (Ink) or high-contrast accent (Brass).
- **Cards:** Clean white with subtle elevation or "ledger" style with a side accent.
